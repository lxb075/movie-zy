🚀 本项目介绍

🎬 影视推荐墙

一个纯前端开发的影视推荐展示网站，支持电影和动漫分类浏览、搜索筛选、点赞收藏、评分评价、留言互动等功能。采用现代暗色主题设计，支持亮色/暗色模式切换，完全响应式布局，可在手机和电脑上流畅访问。

✨ 核心功能

• 多种筛选方式（类型、类型） · 点赞和收藏功能 · 评分评价系统 · 留言板互动 · 图片放大查看 · 返回顶部导航 · 主题切换 · 响应式适配

🛠️ 技术栈

HTML5 + CSS3 + JavaScript（原生）+ localStorage 数据持久化 + Intersection Observer 图片懒加载 + CSS 动画效果 + GitHub Pages 部署
